# Shell'Naga for Scoop

Scoop bucket for [Shell'Naga](https://shellnaga.sh), a native terminal for Windows.

```powershell
scoop bucket add shellnaga https://github.com/shellnaga/scoop-shellnaga
scoop install shellnaga/shellnaga
```

Update with `scoop update shellnaga`. The manifest follows the release on
[shellnaga.sh](https://shellnaga.sh/downloads/SHA256SUMS.txt). License: the
[Shell'Naga EULA](https://shellnaga.sh/eula/).
